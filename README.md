## 📌 About The Project

A modern, responsive, and interactive personal developer portfolio built with pure HTML5, CSS3, and JavaScript. Designed with a sleek dark aesthetic, glassmorphic UI elements, dynamic neural network animations, and a rich project showcase with full modal exploration.

### ✨ Key Features

- 🎨 **Modern Dark UI & Theme Toggle**: Ultra-clean dark theme with indigo/violet gradients, glassmorphism, and toggleable light mode.
- 🧠 **Interactive Neural Network Canvas**: Ambient interactive particle background that reacts to cursor movement.
- 📱 **Fully Responsive Design**: Optimized across mobile smartphones, tablets, laptops, and ultra-wide screens.
- 📂 **Dynamic Projects Showcase**:
  - Filter by **Mobile Applications**, **Web Development**, and **Desktop Systems**.
  - Interactive project detail modals with full feature breakdowns and tech tags.
  - Built-in project management system allowing on-the-fly editing, deleting, and adding of projects.
- 📄 **Interactive Resume / CV Viewer**: Integrated CV modal with direct download and preview capabilities.
- 📬 **Live Contact System**: Contact form with input validation and direct links to social profiles.

## 💻 Local Development

To run this portfolio locally on your machine:

1. Clone this repository:
   ```bash
   git clone https://github.com/bldewasurendra/My-protfolio.git
   ```
2. Navigate into the project folder:
   ```bash
   cd My-protfolio
   ```
3. Start a local server (e.g. using Python):
   ```bash
   python -m http.server 3000
   ```
4. Open your browser and navigate to `http://localhost:3000`.
